# Lab-Only Assets

This directory stores non-canonical experimentation artifacts used by Axis Lab.

Use this area for exploratory prompts/examples/lexicons/policy bundle previews that are
not yet promoted into world-scoped policy paths.

Supported resolver precedence now treats these as lower than world-scoped
assets.

Important boundary:

- files here are explicitly lab-only and non-canonical
- this directory is the right place for experimental local assets that should
  not be mistaken for mud-server authority
- older legacy fallback paths are being removed rather than preserved
