Micro-Indicators
================

Structural Learning Layer: deterministic heuristic classifiers that label
transformation-map rows with structural shift indicators (e.g. *compression*,
*embodiment shift*, *intensity ↑*).

Uses NLTK for POS tagging and sentence segmentation, and JSON lexicon data
from the repo's checked-in lexicon resources.
